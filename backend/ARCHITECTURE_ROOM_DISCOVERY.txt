╔═══════════════════════════════════════════════════════════════════════════╗
║                         PAGINATION LOGIC                                  ║
╚═══════════════════════════════════════════════════════════════════════════╝

Input:  page=2, limit=20
        ↓
Offset: (2-1) * 20 = 20
        ↓
Query:  SELECT * ... LIMIT 20 OFFSET 20
        ↓
hasNext: (20 + 20) < total
        ↓
Output: Items 21-40 of total

╔═══════════════════════════════════════════════════════════════════════════╗
║                          INDEX STRATEGY                                   ║
╚═══════════════════════════════════════════════════════════════════════════╝

Single Composite Index: (is_public, likes_count DESC, created_at DESC)

Popular Query (likes first):
  ✓ WHERE is_public = 1               → Index: exact match
  ✓ ORDER BY likes_count DESC         → Index: direct scan
  ✓ ORDER BY created_at DESC          → Index: included in scan

Recent Query (created_at first):
  ✓ WHERE is_public = 1               → Index: exact match
  ✓ ORDER BY created_at DESC          → Index: reverse scan
  ✓ ORDER BY likes_count DESC         → Index: tie-breaker

Performance: < 100ms total response time
