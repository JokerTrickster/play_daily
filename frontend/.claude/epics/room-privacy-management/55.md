# Task: Join Room API Implementation

## Description
Implement the `POST /v0.1/rooms/join` endpoint to allow users to join rooms by room code. Public rooms allow direct join, while private rooms require password validation. Prevent duplicate memberships and provide appropriate error responses.

## Acceptance Criteria
- [ ] POST endpoint `/v0.1/rooms/join` implemented
- [ ] Request body accepts `room_code` and optional `password`
- [ ] Authentication required (must be logged in user)
- [ ] Check existing membership first - return success if already member
- [ ] Public rooms (`is_public=true`): allow join without password
- [ ] Private rooms (`is_public=false`): require password validation
- [ ] Wrong password returns 401 Unauthorized with error message
- [ ] Already member returns 409 Conflict (or 200 success, see note)
- [ ] Non-existent room returns 404 Not Found
- [ ] New member added with `READ_ONLY` permission
- [ ] Response includes room details and user's permission level

**Handler Implementation** (`joinRoomHandler.go`):
```go
type JoinRoomRequest struct {
    RoomCode string  `json:"room_code" validate:"required"`
    Password *string `json:"password,omitempty"`
}

type JoinRoomResponse struct {
    Room struct {
        ID          uint   `json:"id"`
        RoomCode    string `json:"room_code"`
        Name        string `json:"name"`
        IsPublic    bool   `json:"is_public"`
        LikesCount  uint   `json:"likes_count"`
        MemberCount uint   `json:"member_count"`
    } `json:"room"`
    Permission string `json:"permission"` // "READ_ONLY"
    IsNewMember bool  `json:"is_new_member"` // false if already member
}

func (h *Handler) JoinRoom(c echo.Context) error {
    userID := c.Get("user_id").(uint)

    var req JoinRoomRequest
    if err := c.Bind(&req); err != nil {
        return c.JSON(400, map[string]string{
            "error": "Invalid request body",
        })
    }

    room, isNewMember, err := h.useCase.JoinRoom(userID, req.RoomCode, req.Password)
    if err != nil {
        switch err {
        case ErrRoomNotFound:
            return c.JSON(404, map[string]string{
                "error": "Room not found",
            })
        case ErrInvalidPassword:
            return c.JSON(401, map[string]string{
                "error": "Invalid password",
            })
        default:
            return c.JSON(500, map[string]string{
                "error": "Failed to join room",
            })
        }
    }

    return c.JSON(200, JoinRoomResponse{
        Room:        room,
        Permission:  "READ_ONLY",
        IsNewMember: isNewMember,
    })
}
```

**UseCase Implementation** (`joinRoomUseCase.go`):
```go
var (
    ErrRoomNotFound    = errors.New("room not found")
    ErrInvalidPassword = errors.New("invalid password")
)

func (uc *UseCase) JoinRoom(userID uint, roomCode string, password *string) (*models.Room, bool, error) {
    // 1. Find room by code
    room, err := uc.roomRepo.FindByRoomCode(roomCode)
    if err != nil {
        return nil, false, ErrRoomNotFound
    }

    // 2. Check existing membership
    existingMember, err := uc.memberRepo.FindByRoomAndUser(room.ID, userID)
    if err == nil && existingMember != nil {
        // Already a member - return success (idempotent)
        return room, false, nil
    }

    // 3. Validate access based on privacy setting
    if !room.IsPublic {
        // Private room - require password
        if password == nil || room.Password == nil {
            return nil, false, ErrInvalidPassword
        }
        if *password != *room.Password {
            return nil, false, ErrInvalidPassword
        }
    }
    // Public rooms proceed without password check

    // 4. Add member with READ_ONLY permission
    member := &models.RoomMember{
        RoomID:     room.ID,
        UserID:     userID,
        Permission: models.PermissionReadOnly,
    }

    if err := uc.memberRepo.Create(member); err != nil {
        return nil, false, err
    }

    return room, true, nil
}
```

**Validation Logic Flow**:
```
1. Find room by room_code
   ├─ Not found → 404 Not Found
   └─ Found → Continue

2. Check existing membership
   ├─ Already member → 200 Success (isNewMember: false)
   └─ Not member → Continue

3. Check room privacy
   ├─ Public (is_public=true)
   │  └─ Add member → 200 Success (isNewMember: true)
   └─ Private (is_public=false)
      ├─ No password provided → 401 Unauthorized
      ├─ Wrong password → 401 Unauthorized
      └─ Correct password → Add member → 200 Success (isNewMember: true)
```
