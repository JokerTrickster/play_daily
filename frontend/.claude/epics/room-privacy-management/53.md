# Task: Privacy Toggle API Implementation

## Description
Implement the `PUT /v0.1/rooms/:room_id/privacy` endpoint to allow room owners to toggle between public and private modes. When switching to private, generate a crypto-secure 4-digit password. Only the room owner can modify privacy settings.

## Acceptance Criteria
- [ ] PUT endpoint `/v0.1/rooms/:room_id/privacy` implemented
- [ ] Request validates user is room owner (owner_user_id matches authenticated user)
- [ ] Request body accepts `is_public` boolean field
- [ ] Switching to private (`is_public=false`) generates 4-digit random password
- [ ] Switching to public (`is_public=true`) sets password to NULL
- [ ] Password generation uses crypto-secure randomization
- [ ] Response includes new room state with password (if private)
- [ ] Unauthorized users receive 403 Forbidden response
- [ ] Non-existent rooms receive 404 Not Found response
- [ ] Database update is atomic (transaction-safe)

type UpdateRoomPrivacyRequest struct {
    IsPublic bool `json:"is_public" validate:"required"`
}

type UpdateRoomPrivacyResponse struct {
    ID       uint    `json:"id"`
    RoomCode string  `json:"room_code"`
    IsPublic bool    `json:"is_public"`
    Password *string `json:"password,omitempty"`
}

func (h *Handler) UpdateRoomPrivacy(c echo.Context) error {
    roomID := c.Param("room_id")
    userID := c.Get("user_id").(uint)

    var req UpdateRoomPrivacyRequest
    if err := c.Bind(&req); err != nil {
        return c.JSON(400, "Invalid request body")
    }

    room, err := h.useCase.UpdateRoomPrivacy(roomID, userID, req.IsPublic)
    if err != nil {
        // Handle 403 if not owner, 404 if room not found
    }

    return c.JSON(200, UpdateRoomPrivacyResponse{
        ID:       room.ID,
        RoomCode: room.RoomCode,
        IsPublic: room.IsPublic,
        Password: room.Password,
    })
}

**UseCase Implementation** (`updateRoomPrivacyUseCase.go`):
```go
func (uc *UseCase) UpdateRoomPrivacy(roomID string, userID uint, isPublic bool) (*models.Room, error) {
    // 1. Find room
    room, err := uc.roomRepo.FindByID(roomID)
    if err != nil {
        return nil, ErrRoomNotFound
    }

    // 2. Validate ownership
    if room.OwnerUserID != userID {
        return nil, ErrNotRoomOwner
    }

    // 3. Update privacy settings
    room.IsPublic = isPublic
    if !isPublic {
        // Generate password for private room
        password := utils.GenerateRoomPassword()
        room.Password = &password
    } else {
        // Clear password for public room
        room.Password = nil
    }

    // 4. Save atomically
    if err := uc.roomRepo.Update(room); err != nil {
        return nil, err
    }

    return room, nil
}
```

**Password Generator** (`passwordGenerator.go`):
```go
package utils

import (
    "crypto/rand"
    "fmt"
    "math/big"
)

// GenerateRoomPassword generates a cryptographically secure 4-digit password
func GenerateRoomPassword() string {
    max := big.NewInt(10000) // 0000-9999
    n, err := rand.Int(rand.Reader, max)
    if err != nil {
        // Fallback to math/rand if crypto/rand fails
        return fmt.Sprintf("%04d", mathrand.Intn(10000))
    }
    return fmt.Sprintf("%04d", n.Int64())
}
```
