# Task: Update Room Model with Privacy Fields

## Description
Update the Go Room struct in GORM model to include new privacy control fields (`is_public`, `password`) with proper GORM tags for database mapping.

## Acceptance Criteria
- [ ] `IsPublic` field added to Room struct with correct GORM tags
- [ ] `Password` field added as pointer to string (nullable)
- [ ] GORM tags include proper column names, types, and indexes
- [ ] JSON serialization tags configured correctly
- [ ] Password field uses `omitempty` to hide when null
- [ ] Model compiles without errors
- [ ] Existing room queries still work after model update

## Technical Details
**File Location**: `backend/src/common/db/mysql/gormDB.go`

**Changes to Room struct**:
```go
type Room struct {
    gorm.Model
    RoomCode    string  `json:"room_code" gorm:"column:room_code;type:varchar(50);uniqueIndex;not null;comment:방 고유 코드 (UUID)"`
    Name        string  `json:"name" gorm:"column:name;type:varchar(100);not null;comment:방 이름"`
    LikesCount  uint    `json:"likes_count" gorm:"column:likes_count;type:int unsigned;default:0;index;comment:좋아요 개수"`
    OwnerUserID uint    `json:"owner_user_id" gorm:"column:owner_user_id;not null;index;comment:방 소유자 ID"`

    // NEW FIELDS
    IsPublic    bool    `json:"is_public" gorm:"column:is_public;not null;default:false;index;comment:방 공개 여부 (true=퍼블릭, false=프라이빗)"`
    Password    *string `json:"password,omitempty" gorm:"column:password;type:varchar(4);comment:방 비밀번호 (4자리 숫자, 퍼블릭 방은 NULL)"`

    Owner       *User   `json:"owner,omitempty" gorm:"foreignKey:OwnerUserID"`
    Memos       []Memo  `json:"memos,omitempty" gorm:"foreignKey:RoomID;constraint:OnDelete:CASCADE"`
}
```

**Key Considerations**:
- `IsPublic` is non-nullable boolean (defaults to false for safety)
- `Password` is nullable pointer for public rooms (NULL = no password)
- `omitempty` in JSON tag prevents exposing null passwords in API responses
- Index on `is_public` for fast discovery queries
