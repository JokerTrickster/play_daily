# Task: Database Migration for Room Privacy

## Description
Create and execute database migration to add privacy control fields (`is_public`, `password`) to the rooms table. Backfill existing rooms with current user passwords and set them as private by default.

## Acceptance Criteria
- [ ] Migration script creates `is_public` BOOLEAN column (default: false)
- [ ] Migration script creates `password` VARCHAR(4) column (nullable)
- [ ] Composite index created: `idx_room_discovery (is_public, likes_count, deleted_at)`
- [ ] Index created for member validation: `idx_room_members_validation (room_id, user_id, deleted_at)`
- [ ] Existing rooms backfilled with user's room password
- [ ] All existing rooms set to `is_public = false`
- [ ] Migration tested on dev environment with rollback capability
- [ ] Zero data loss or corruption during migration

## Technical Details
**File Location**: `backend/src/common/db/mysql/migration_add_room_privacy.sql`

**Migration SQL**:
```sql
-- Add privacy fields
ALTER TABLE rooms
  ADD COLUMN is_public BOOLEAN NOT NULL DEFAULT false
    COMMENT 'Room visibility (true=public, false=private)' AFTER owner_user_id,
  ADD COLUMN password VARCHAR(4) NULL
    COMMENT '4-digit room password (NULL for public rooms)' AFTER is_public,
  ADD INDEX idx_room_discovery (is_public, likes_count, deleted_at);

-- Backfill existing rooms
UPDATE rooms r
INNER JOIN users u ON u.default_room_id = r.id
SET r.password = u.room_password, r.is_public = false
WHERE r.password IS NULL;

-- Optimize member validation
CREATE INDEX idx_room_members_validation
  ON room_members(room_id, user_id, deleted_at);
```

**Rollback SQL**:
```sql
ALTER TABLE rooms
  DROP COLUMN is_public,
  DROP COLUMN password,
  DROP INDEX idx_room_discovery;
DROP INDEX idx_room_members_validation ON room_members;
```
