# Task: Public Room Discovery API

## Description
Implement the `GET /v0.1/rooms/public` endpoint to retrieve a paginated list of public rooms sorted by popularity (likes count). Include owner details and member count for each room to enable rich discovery UI.

## Acceptance Criteria
- [ ] GET endpoint `/v0.1/rooms/public` implemented
- [ ] Query parameter `page` (default: 1, min: 1)
- [ ] Query parameter `limit` (default: 10, min: 1, max: 50)
- [ ] Filters rooms where `is_public = true` and `deleted_at IS NULL`
- [ ] Results sorted by `likes_count DESC` (most popular first)
- [ ] Response includes owner details (id, nickname, profile_image)
- [ ] Response includes member count per room
- [ ] Pagination metadata included (total_count, current_page, total_pages)
- [ ] Invalid pagination parameters return 400 Bad Request
- [ ] Response time <1s for 1000+ public rooms

**Handler Implementation** (`getPublicRoomsHandler.go`):

```go
type GetPublicRoomsRequest struct {
    Page  int `query:"page" validate:"min=1"`
    Limit int `query:"limit" validate:"min=1,max=50"`
}

type PublicRoomResponse struct {
    ID          uint   `json:"id"`
    RoomCode    string `json:"room_code"`
    Name        string `json:"name"`
    LikesCount  uint   `json:"likes_count"`
    MemberCount uint   `json:"member_count"`
    Owner       struct {
        ID           uint   `json:"id"`
        Nickname     string `json:"nickname"`
        ProfileImage string `json:"profile_image"`
    } `json:"owner"`
}

type GetPublicRoomsResponse struct {
    Rooms      []PublicRoomResponse `json:"rooms"`
    Pagination struct {
        CurrentPage int `json:"current_page"`
        TotalPages  int `json:"total_pages"`
        TotalCount  int `json:"total_count"`
        PerPage     int `json:"per_page"`
    } `json:"pagination"`
}

func (h *Handler) GetPublicRooms(c echo.Context) error {
    var req GetPublicRoomsRequest
    req.Page = 1   // Default
    req.Limit = 10 // Default

    if err := c.Bind(&req); err != nil {
        return c.JSON(400, "Invalid query parameters")
    }

    rooms, totalCount, err := h.useCase.GetPublicRooms(req.Page, req.Limit)
    if err != nil {
        return c.JSON(500, "Failed to fetch public rooms")
    }

    response := BuildPublicRoomsResponse(rooms, totalCount, req.Page, req.Limit)
    return c.JSON(200, response)
}
```

**UseCase Implementation** (`getPublicRoomsUseCase.go`):
```go
func (uc *UseCase) GetPublicRooms(page, limit int) ([]models.Room, int64, error) {
    offset := (page - 1) * limit

    var rooms []models.Room
    var totalCount int64

    // Count total public rooms
    if err := uc.db.Model(&models.Room{}).
        Where("is_public = ? AND deleted_at IS NULL", true).
        Count(&totalCount).Error; err != nil {
        return nil, 0, err
    }

    // Fetch paginated rooms with owner details
    if err := uc.db.
        Where("is_public = ? AND deleted_at IS NULL", true).
        Preload("Owner").
        Order("likes_count DESC").
        Limit(limit).
        Offset(offset).
        Find(&rooms).Error; err != nil {
        return nil, 0, err
    }

    // Fetch member counts for each room
    for i := range rooms {
        var memberCount int64
        uc.db.Model(&models.RoomMember{}).
            Where("room_id = ? AND deleted_at IS NULL", rooms[i].ID).
            Count(&memberCount)
        rooms[i].MemberCount = uint(memberCount) // Add this field to Room model
    }

    return rooms, totalCount, nil
}
```

**Query Optimization**:
- Uses `idx_room_discovery` index from Task 001 migration
- Preloads owner in single query (avoids N+1 problem)
- Member count could be optimized with JOIN or subquery if performance issues arise
